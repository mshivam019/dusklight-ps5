Dusklight for PS5

Requires a jailbroken PS5 with a compatible native-title loader.
Tested on firmware 9.00 using kstuff and ShadowMount. No game dump or texture pack is included.

1. Extract the ZIP. The title is output/PPSA99640.
2. Add your own USA or European/PAL GameCube revision-0 raw ISO or GCM to
   /data/dusklight/PPSA99640/images/. Names other than game.iso are accepted.
   Alternatively put it beside eboot.bin; the first launch imports it safely.
   Wii discs are unsupported. Convert compressed GameCube images (including
   RVZ/CISO) to raw ISO before copying them; changing the filename is insufficient.
3. Close the title before installing or updating. Let the first data import finish
   before a Store update: images and user/ are copied and byte-verified under
   /data/dusklight/PPSA99640/, outside the app folder. Keep this data directory.
   The launch picture can remain visible for several minutes during copying and
   verification. Leave the title running until its menu appears. Originals are
   retained; interrupted copies restart safely. Additional free space is needed.
4. Upload the complete title folder to /mnt/ext1/etaHEN/games/PPSA99640 with any FTP client.
   Linux/macOS: bash tools/install.sh --src output/PPSA99640 --console <console-ip>
   Windows: powershell -ExecutionPolicy Bypass -File tools/install.ps1 -Src output/PPSA99640 -Console <console-ip>
   The helpers require Python 3 and preserve an existing user/config.json.
5. Register/mount the folder with your native-title launcher or PS5 Upload, then launch it.

Controls: Cross=A, Circle=B, Square=X, Triangle=Y, Options=Start.
Touchpad opens Dusklight settings. Sticks control movement/camera; L2/R2 are triggers.

Startup interface language:
Choose Menu language / Menüsprache on the launch screen, select English or Deutsch,
then close and reopen the app. The preference survives app-folder replacement.
It controls the startup interface independently from game text. Common settings
labels are translated too; advanced help without a translation remains English.
The first launch with this option shows the menu once for existing installations.

Built-in PS5 button artwork uses the default A/B/X/Y/Z mapping. User texture packs
have higher priority. The existing texture replacement switch controls this art.
The first player's controller follows the game user. Existing other console users are not reassigned.

Defaults: automatic internal resolution, 4K output on the tested display, 60 FPS frame interpolation,
200% Dusklight menu scale, no FPS/controller/shader-compilation launch overlays.
Interpolation does not change the original game simulation rate.

Optional HD textures and PlayStation prompts:
Download the PC pack and controller addon from:
https://www.henrikomagnifico.com/zelda-twilight-princess-4k
Install Pillow in your Python environment, then run:
python tools/prepare-textures.py --pack <pack.zip> --buttons <addon.zip> --out <new-folder>
Copy the prepared folder beneath PPSA99640/user/texture_replacements/ while the title is closed.
The PC addon requires no ASTC decoder. The mobile addon requires --astcenc <host-decoder>.
Do not include downloaded/converted texture packs in public releases without the author's permission.

Disc selection and updates:
The PS5 Select Disc Image button uses an in-app controller-operated list, because
desktop file dialogs are unavailable on the console. It lists supported protected
images and uses Dusklight's existing verification. A changed disc requires a restart.
One available image is selected automatically; multiple images require a selection.
Existing USA behavior, graphics presets and controller mappings are unchanged.

Existing protected user files take priority, then /download0/user before app defaults.
Top-level images and user/ in /data/prosperostore/previous/<TITLEID> are also imported
when that Store backup is available. Different images with the same name get numbered
names. Compressed images are preserved as data but cannot be played by this backend.
Backups on other drives need manual recovery. Data deleted before a completed import
cannot be recovered. No app can guarantee the behavior of an external updater.
